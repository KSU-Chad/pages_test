--- layout: page # All the Categories of posts --- {% include lang.html %} {% comment %} This layout builds the main Modules tab. It is a project-local override of Chirpy's categories layout. Post front matter defines the hierarchy. For example: categories: [Module 01, Introduction] The first value becomes the large module card. The second value becomes a row inside that card. To add future modules, create posts with the same two-level pattern; this file discovers the categories automatically. A second-level category containing one post links straight to that post. A category containing multiple posts links to its category listing instead. Jekyll category names are global, so reusing a name such as `Introduction` in several modules makes those posts members of the same category. Use unique second-level names if each one must always retain a direct single-post link. {% endcomment %} {% assign HEAD_PREFIX = 'h_' %} {% assign LIST_PREFIX = 'l_' %} {% assign group_index = 0 %} {% assign sort_categories = site.categories | sort %} {% for category in sort_categories %} {% assign category_name = category | first %} {% assign posts_of_category = category | last %} {% assign first_post = posts_of_category | first %} {% comment %} Only create a large card when this category is the first category on its posts.
