**Exploration only. No code to write.** You'll run the simulation, look at what the sensors publish, and write down what you find. Fill in the blanks as you go. Your answers are your lab report.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| Gazebo opens but no walls | World didn't load | Check the launch command and the world path |
| `gz topic -l` has no sensor topics | Sensors plugin missing in the world | Check `my_world.sdf` still has the `gz-sim-sensors-system` plugin |
| `ros2 topic list` has no `scan_raw` | Bridge died | Read the Terminal 1 output for `process has died` |
| LaserScan blank in RViz | QoS or Fixed Frame | Set Best Effort, set Fixed Frame to `odom` |
| Everything is slow (rates low) | Lab machine rendering | Measure with `--use-sim-time`. Close other windows |
| Robot doesn't move | Gate not running or motion disabled | Start the gate, check `/enable_motion` |
| RViz shows "no transform" | RViz not on sim time | Restart with `use_sim_time:=true` |
| Point cloud rotated | Known frame issue | Record what you see (Part 7) |
