If `module_post_order` in _config.yml is anything except `oldest`, the list is reversed to newest-to-oldest. Change the setting in _config.yml rather than editing this sorting code. {% endcomment %} {% assign ordered_posts = page.posts | sort: 'date' %} {% unless site.module_post_order == 'oldest' %} {% assign ordered_posts = ordered_posts | reverse %} {% endunless %}
